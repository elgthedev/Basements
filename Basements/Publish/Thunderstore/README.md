# Basements

Expand into the earth with a placeable basement. Compatible with Valheim 1.0 Deep North Update.

## Features

- Adds Basement to the hammer's Misc. build category.
- Supports nested basements; the default limit is five levels.
- Allows unrestricted building inside the basement.
- Returns construction materials when dismantled after its interior is clear.

Install with Gale, or install BepInExPack for Valheim and place `Basements.dll` in `Valheim/BepInEx/plugins/`. The same package should be installed on the server when using synchronized server configuration. ServerSync is bundled.

See the [full Basements documentation](https://valheim.hexium.gg/mods/OdinPlus/Basements) for configuration, compatibility, and troubleshooting.
